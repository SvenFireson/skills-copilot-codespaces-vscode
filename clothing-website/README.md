# Stylish Threads Website

This folder contains a simple example website for a fictional clothing brand called **Stylish Threads**.

## Running locally

Open `index.html` in your browser to view the site. No additional dependencies are required.

The website uses placeholder images from [placeholder.com](https://via.placeholder.com/) that you can replace with your own product photography.

## File overview

- `index.html` – main HTML page
- `style.css` – styling for the site
- `script.js` – small JavaScript for product click alerts
